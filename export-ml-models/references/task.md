# Task reference

The comparison helper checks numeric finite JSON arrays for shape and elementwise absolute/relative tolerance. It is independent of ONNX and cannot prove graph validity, task-quality parity or provider support. Some formats separate graph and weights; include all required files. Read references/tools.md. Prefer the current framework exporter over copied deprecated examples.

Primary sources:
- https://onnx.ai/onnx/intro/concepts.html
- https://docs.pytorch.org/docs/stable/onnx.html
- https://onnxruntime.ai/docs/reference/compatibility.html

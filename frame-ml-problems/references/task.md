# Task reference

Use a short decision record: prediction time; target horizon; independent unit; available features; excluded post-outcome features; metric and threshold policy; target population; error cost; resource limits; minimum useful improvement; evaluation ownership. A high accuracy can be trivial under class imbalance. Offline predictive lift is not an estimate of business impact without an appropriate online evaluation.

- https://scikit-learn.org/stable/modules/model_evaluation.html

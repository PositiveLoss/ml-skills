# Task reference

Optimization over many trials increases selection bias. A sampler seed does not guarantee deterministic concurrent scheduling; record topology and trial state. Conditional parameters should not generate invalid combinations. Early stopping on validation is part of selection and must be represented in the evaluation protocol.

- https://optuna.readthedocs.io/en/stable/
- https://scikit-learn.org/stable/modules/grid_search.html

# Task reference

Isolation/density/reconstruction scores use different scales and assumptions. LocalOutlierFactor novelty and training-fit behavior are not interchangeable. Synthetic anomalies can be useful sensitivity tests but may be easier than genuine failure modes. Cluster related alerts when measuring operational event detection.

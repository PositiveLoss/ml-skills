# Task reference

Rust ONNX bindings can be community-maintained and have runtime-version constraints. Burn API/backend capabilities evolve; inspect the selected crate docs rather than importing Python assumptions. An owned Rust handle does not alone establish native-thread safety or deterministic inference. Treat GPU features and model conversion routes as backend-specific.

Primary sources:
- https://docs.rs/ort/latest/ort/
- https://github.com/tracel-ai/burn
- https://onnxruntime.ai/docs/get-started/community-projects.html

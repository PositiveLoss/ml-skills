# Task reference

Concept drift concerns the target relationship; covariate shift concerns inputs and need not imply degraded predictions. Delayed labels can make recent cohorts appear artificially good or bad. Repeated significance tests inflate false alarms. Monitor decision threshold and abstention policy alongside score distributions.

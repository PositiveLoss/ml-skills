# Task reference

Gonum supplies numerical primitives useful for ML, not an automatic model training/evaluation protocol. For local deep-model inference, use a verified binding or a narrow C ABI integration; for services preserve deadlines/schema/model identity. Measure copying and cgo/native thread interactions. Do not claim free concurrency from goroutine count alone.

Primary sources:
- https://pkg.go.dev/gonum.org/v1/gonum
- https://onnxruntime.ai/docs/get-started/with-c.html

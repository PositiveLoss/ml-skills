# Task reference

A scheduler such as Prefect controls execution, not scientific correctness. A model registry status does not mean a model was tested on the intended population. Persist outputs outside worker scratch and verify hash/version references. Do not automatically retrain/promote on every drift alert without the declared policy.

- https://docs.prefect.io/
